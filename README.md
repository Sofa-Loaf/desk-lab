# Desk Lab

Free, client-side interactive computer desk for sales demos and troubleshooting.

Click Dell OptiPlex, Precision laptops, WD19 docks, monitors, and UPS units. Zoom to labeled ports. Configure what’s on the desk. Guided tips (e.g. WD19 power jack).

No account. No backend. No Stripe. Accuracy of labels over photorealism.

**Live:** https://28to3.me/apps/desk-lab.html
